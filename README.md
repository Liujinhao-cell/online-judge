📖 项目简介
沙箱判官是一个对标 LeetCode 的在线代码评测平台，支持用户注册登录、题目管理、代码提交、自动判题以及竞赛排名。项目核心挑战在于保证判题结果的准确性以及代码运行环境的安全隔离。
项目名称寓意：像“判官”一样公正评判每一段代码，同时用“沙箱”技术守护系统安全。
